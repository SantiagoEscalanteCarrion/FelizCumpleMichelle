# Feliz Cumpleaños Michelle ♡

---

## Versión web (iPhone / cualquier celular)

### Archivos necesarios en la misma carpeta:
- `index.html`
- `michelle.jpeg`
- `gone_gone_gone.mp3` ← **tú consigues este archivo** (ver abajo)

### Cómo conseguir la canción
1. Descarga "Gone Gone Gone – Phillip Phillips" como MP3 (desde YouTube, Spotify, etc.)
2. Renómbrala exactamente `gone_gone_gone.mp3`
3. Ponla en la misma carpeta que `index.html`

### Cómo publicarla en internet (GitHub Pages — gratis)

1. Ve a **github.com** → New repository → nombre: `feliz-cumple-michelle` → Public → Create
2. Sube los 3 archivos (`index.html`, `michelle.jpeg`, `gone_gone_gone.mp3`) con el botón **Add file → Upload files**
3. Ve a **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save**
4. Espera ~1 minuto y tu link quedará en:
   `https://TU_USUARIO.github.io/feliz-cumple-michelle`
5. Mándale ese link a Michelle por WhatsApp 🎉

### Qué verá ella
- Pantalla "Toca para abrir tu regalo"
- El texto se escribe letra a letra con música de fondo
- Cuando el texto termina, la foto aparece con efecto de línea de escaneo
- Botón **Saltar →** si quiere saltarse la animación

## Versión escritorio (solo PC/Mac, requiere Python)

### 1. Instalar dependencias
```bash
pip install pygame
```

### 2. Ejecutar
```bash
python feliz_cumple.py
```

### Controles
- **ESC** → cerrar
- **Espacio / Enter** → saltar animación
