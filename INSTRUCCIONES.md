# Feliz Cumpleaños Michelle ♡

## Cómo ejecutar

### 1. Instalar dependencias
```bash
pip install pygame
```

### 2. Coloca la imagen
Guarda la foto como `michelle.jpg` en esta misma carpeta.

### 3. Ejecutar
```bash
python feliz_cumple.py
```

---

## Controles
- **ESC** → cerrar
- **Espacio / Enter** → saltar la animación al final

---

## Qué hace
- La imagen se va revelando de arriba hacia abajo con una línea de escaneo brillante (~12 segundos)
- El texto aparece letra a letra mientras la imagen se dibuja
- Partículas flotantes de colores de fondo
- El texto hace scroll automático conforme avanza
